# Bikeshare Data Analysis

## Project Overview

This project uses Python to explore bikeshare trip data
from New York City.

It helps users understand bike-sharing patterns and
practice data analysis using Python.

## Requirements

- Python 3
- Required Python libraries
- New York City bikeshare dataset

## How to Run

1. Open the project folder.
2. Make sure `new_york_city.csv` is in the project folder.
3. Install the libraries required by `bikeshare.py`.
4. Run the program:

```bash
python bikeshare.py
```

## Note

The dataset is not uploaded to GitHub because it is listed in `.gitignore`.
